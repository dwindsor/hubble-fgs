The "TCP Throughput / Socket - Host Binaries" dashboard shows TCP packets and bytes counts for host binaries (that is, not Kubernetes pods) only. It also highlights retransmits, socket drops and zero window packets. It's designed as a troubleshooting tool, so it allows filtering by an arbitrary selection of nodes, binaries and remote DNS names. The top row shows the overview for the selection and the following rows split the data by different dimensions.
