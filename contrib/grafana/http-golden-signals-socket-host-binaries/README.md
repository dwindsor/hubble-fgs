The "HTTP Golden Signals / Socket" dashboard shows requests, errors and duration of HTTP requests from the server perspective for host binaries (that is, not Kubernetes pods) only. It's designed as a troubleshooting tool, so it allows filtering by an arbitrary selection of nodes, binaries, remote DNS names and Host headers. The top row shows the overview for the selection and the following rows split the data by different dimensions.

This dashboard requires Tetragon Enterprise with the HTTP sensor configured.
