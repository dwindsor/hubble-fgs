The "TCP Latency / Socket - Host Binaries" dashboard shows TCP latency (one-way) and SRTT (smoothed round trip time) for host binaries (that is, not Kubernetes pods) only. It's designed as a troubleshooting tool, so it allows filtering by an arbitrary selection of nodes, binaries and remote DNS names. The top row shows the overview for the selection and the following rows split the data by different dimensions.
